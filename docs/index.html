Principles

Cubicle is a dense, tactile CSS framework for critical enterprise tools: IAM portals, VPN admin panels, infrastructure consoles and back-office dashboards.

Neo-enterprise utilitarianism

  • Inspiration, not imitation. The functional design code of classic enterprise software (clear affordances, tactile depth, high density, unambiguous states) without pixel fonts or retro gimmicks.
  • Clarity over decoration. Every border, shadow and background shift groups data, signals interactivity or shows system state.
  • Tactile and realistic. Buttons look raised and travel 1px when pressed; inputs and wells look recessed; containers have physical boundaries.

Visual language

  • Cool industrial steel neutrals separate workspaces; colour is reserved for status and primary actions, in desaturated enterprise tones.
  • Sharp corners or micro-radii only (0–3px). No pills, no large rounded cards.
  • Visible 1px borders between cells, groups and panels; text meets WCAG AA; keyboard focus shows a 2px accent ring.
  • Compact 13px base text, monospace for technical data, tabular figures for every number.

Forbidden

  • Glassmorphism, neomorphism, blur, glowing borders.
  • Transitions slower than 50ms; bouncy easing.
  • Borderless “ghost” inputs that only show an underline on focus.
  • Marketing patterns: hero banners, pricing cards, oversized type.

Integration

  • Link dist/cubicle.css; no build step and no dependencies.
  • The base layer sets document typography, links, monospace and the focus ring only. Native controls, tables and fieldsets get the Cubicle look through cb-* classes.
  • All rules live in cascade layers (reset, tokens, base, layout, components, utilities), so unlayered host CSS overrides any of them without !important.
  • States use standard attributes (disabled, aria-invalid, aria-selected…), so server-driven swaps work without class toggling.

Base typography

The base layer sets the sans stack at 13px on the canvas, accent-coloured underlined links, and the monospace stack for code, kbd, samp and pre. No class is required.
